VÉRION Banking System

Tecnologia, inovação e soluções financeiras.

O VÉRION é um sistema bancário desenvolvido com Python, Flask e SQLite, com o objetivo de simular operações financeiras e aplicar conceitos de desenvolvimento Back-end.

Funcionalidades

* Cadastro de clientes.
* Criação de contas bancárias.
* Login e autenticação de usuários.
* Consulta de saldo.
* Depósitos.
* Saques.
* Transferências entre contas.
* Histórico de movimentações financeiras.

Tecnologias utilizadas

* Python
* Flask
* SQLite
* HTML5
* CSS3

Objetivo do projeto

Desenvolver uma aplicação que simule o funcionamento de um sistema bancário, explorando conceitos de programação, processamento de dados, gerenciamento de informações e segurança.

Aprendizados

Este projeto busca desenvolver conhecimentos em:

* Lógica de programação.
* Desenvolvimento Back-end.
* Banco de dados SQL.
* Estruturação de sistemas.
* Operações financeiras.

Aviso

O VÉRION é um projeto exclusivamente educacional. Não realiza operações bancárias reais.
